# 🎬 Netflix Catalog Data Analysis (Power BI)

## 📌 Project Overview
This project was developed as part of the Data Visualization module of the DSBA course. The main objective is to analyze the historical evolution of Netflix's catalog, understand the platform's strategic shift between Movies and TV Shows, and identify the most frequent genres.

## 📊 The Dashboard
![Dashboard Overview](images/dashboard_overview.png)

## 🛠️ Tools & Technologies
* **Power BI**: Data modeling, DAX metrics, and interactive visuals.
* **Power Query**: Data cleaning (handling null values and date formatting).
* **Dataset**: Original Kaggle dataset containing listed titles up to 2021.

## 💡 Key Insights
Based on the required charts built for this project (Title Evolution, Movie vs. TV Show Comparison, and Top 10 Genres):
1. **Focus on Movies:** Historically, the catalog has a much higher volume of Movies than TV Shows, although TV Shows have gained significant traction in recent years.
2. **Production Peak:** There was exponential growth in new titles added between 2016 and 2019, reflecting Netflix's aggressive global expansion phase.
3. **Dominant Genres:** "Documentaries" and "Dramas/Comedies" rank among the most common genres on the platform, aligning with global consumer preferences.
